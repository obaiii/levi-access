# Levi access URL

This repository serves `https://levi.kawaitechnologies.com` through GitHub
Pages and redirects visitors to the live Levi NRS e-invoicing application.

The repository intentionally contains no Levi application source, credentials,
invoice data, database files, or OAuth secrets.

## Live destination

`https://lucem-mac-mini-server.tailbd9f6c.ts.net:10000/`

The redirect preserves the requested path, query string, and URL fragment.
